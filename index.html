🎓 Sector Educational Institute Management System

A Next-Generation Enterprise Management System Engineered for Educational Institutes

Project Evolution: Recently improved my 3rd-year university project to this enterprise level. The system is a full-stack, enterprise-grade web application built to streamline operations, financial management, student admissions, attendance, and revenue share analytics for educational institutes.

Designed specifically for Sector Educational Institute (Panadura Campus, Sri Lanka), the system automates day-to-day administrative tasks—ranging from rapid student barcode attendance scanning to automated monthly fee invoicing, teacher commission split reconciliations, cashier counter billing, and instant printable PDF receipt generation.

🌟 Key System Features

📊 Executive Analytics Dashboard

🎓 Student Roster & 360° Profile

Daily student attendance entry supporting instant USB barcode scanner input, code lookups, and status toggles (Present, Absent, Late, Excused) with database persistence across reloads.

Receipt Cashier Counter (F2)

High-speed counter billing modal for Cash, Card, and Bank Transfer collections. Auto-links unpaid monthly invoices, pre-fills cashier inputs, updates financial metrics in real time, and auto-launches printable PDF receipts.

🔍 Global Command Palette (Ctrl + K)

Universal quick search modal accessible via Ctrl + K or Cmd + K to search students, teachers, or trigger system shortcuts across the entire app.

🛒 SL-GreenRoot Market — Secure Inventory Management System

Full-Stack Python & Django 5 Supermarket System with RBAC, nh3 Sanitization & Cloud PostgreSQL

Project Overview: A secure, full-stack Inventory Management System built for "SL-GreenRoot Market" (a Sri Lankan supermarket) using Python, Django, and Tailwind CSS.

Features strict HTML/Markdown sanitization (nh3), Role-Based Access Control (RBAC), cookie hardening, a cashier terminal (POS) Checkout page, production static asset delivery with WhiteNoise, and cloud deployment compatibility for Vercel and PostgreSQL / Supabase.

🌐 Live Application: https://green-root-market.vercel.app/
📁 GitHub Repository: GitHub Repo Link

🌟 Key Features & Security Architecture

🛒 Cashier POS Checkout Terminal

High-speed counter billing modal supporting cart management, CSRF-protected checkout postings, and atomic Django database transactions (transaction.atomic).

🔒 Dual-Pass XSS Protection

Markdown inputs are compiled and sanitized via nh3 (high-performance Rust-based HTML sanitization engine with strict allowlist) before database storage.

🛡️ Role-Based Access Control (RBAC)

Group authorization decorators (@manager_required, @cashier_or_manager_required) that filter incoming HTTP requests and restrict administrative functions.

🍪 Cookie Hardening & Transport Security

Strict browser transport configurations including HttpOnly session/CSRF cookies, SameSite Lax policies, and automated CSRF token parsing on POS JavaScript postings.

⚡ WhiteNoise Production Static Serving

High-performance static file serving directly from Django WSGI without separate web server configuration.

🗄️ Dual Database Architecture

Dynamic configuration via dj-database-url (SQLite for local dev, PostgreSQL / Supabase with persistent connection pooling for production).

🛠️ Technology Stack & Libraries

Full-stack Django MVC Architecture with Tailwind CSS frontend and Supabase PostgreSQL cloud database.

Project Overview: Think of VehicleOS as a digital control center for car dealerships or rental fleets. Instead of using complex spreadsheets, this application provides a visual dashboard to manage vehicle inventory, statuses, and pricing.

📁 GitHub Repository: GitHub Repo Link

🌟 Non-Technical Highlights (Business View)

🛡️ Data Integrity Guardrails

Prevents formatting mistakes, short VIN inputs, or negative pricing via Jakarta Bean Validation annotations.

💻 Technical Architecture & Execution Flow

Decoupled client-server architecture dividing React 19 presentation from Spring Boot 3 backend logic. 

 1. Frontend (React 19) ──────► Native Fetch API (Async HTTP GET/POST/PUT/DELETE)
 2. CORS Security Config  ────► Intercepts and authorizes cross-origin port requests (8080/5173)
 3. Spring MVC Controller ───► Serializes/Deserializes JSON models & Bean Validations
 4. Service Layer ────────────► Enforces business logic & VIN database uniqueness check
 5. Spring Data JPA ──────────► Translates operations to SQL via Hibernate ORM
 6. H2 SQL Database ──────────► Stores active records in high-performance in-memory tables

🔌 REST API Endpoints Summary

Base URL: http://localhost:8080/api/vehicles

Method Endpoint Param Description
GET /api/vehicles search (Optional) Retrieves all vehicles or searches by make, model, color, status, or VIN.
GET /api/vehicles/{id} - Retrieves a single vehicle by primary key ID.
POST /api/vehicles - Registers a new vehicle with unique VIN verification.
PUT /api/vehicles/{id} - Updates details of an existing vehicle by ID.
DELETE /api/vehicles/{id} - Permanently removes a vehicle from fleet records.
